# Rust in Bevy 14：纯函数与几何不变量

碰撞检测先需要一条可验证的几何规则，之后才需要 ECS。把公式困在系统循环里，会让边界条件无法被单独检查。

## 本章唯一主题

将 AABB 相交写成只依赖参数、没有 World 访问的纯函数。

```rust
fn overlaps(a_center: Vec2, a_half: Vec2, b_center: Vec2, b_half: Vec2) -> bool {
    (a_center.x - b_center.x).abs() <= a_half.x + b_half.x
        && (a_center.y - b_center.y).abs() <= a_half.y + b_half.y
}
```

- 相交规则的输入、输出和单位一眼可见。
- `<=` 表示边界接触也算碰撞；改成 `<` 是玩法选择，必须由测试锁定。
- 系统只负责从组件取值、调用函数和处理结果，不能偷偷改变判定公式。

## 设计用法

先测纯函数的重叠、接触、分离和零尺寸情况，再接入 Query。对象数量变多后，空间划分只减少候选对，不改变这条基础判定。

## 练习

为「边缘刚好接触」写一个测试。决定它在你的游戏中是否命中，并让函数名或测试名反映该选择。
