# Rust in Bevy 06：变更检测与增量工作

每帧扫描整个世界常常只是因为程序没有记录「什么变了」。变更检测让系统只为新事实付费。

## 本章唯一主题

使用 Query 的变更过滤器和 `Ref<T>` 的变更状态，区分当前值与本次调度后的变化。

```rust
fn refresh_labels(changed: Query<Entity, Changed<Health>>) {
    for entity in &changed {
        // 只刷新生命值刚被修改过的实体。
        let _ = entity;
    }
}
```

- `Changed<T>` 只匹配自该系统上次运行后被标记为改变的组件。
- 可变借用即使没有改变字段，也可能触发变更标记；先拿 `&T`，确需写入时再拿 `&mut T`。
- 变更检测是增量更新工具，不是可靠的跨帧事件历史。

## 设计用法

组件状态改变后更新 UI、缓存或渲染派生数据，优先使用 `Changed<T>`。需要表达「发生了一次攻击」这类离散事实时，留给第 15 章的 Message 流。

系统受 `run_if` 影响时要特别检查观察间隔：恢复运行后它会看到这段间隔内仍有效的变更。
