# Rust in Bevy 16：组合小规则与显式顺序

巨型 `match` 的问题不在行数，而在于规则间的前后条件无处可见。系统组合把这个依赖关系提到调度层。

## 本章唯一主题

用小系统和 `.chain()` 表达一条有序规则管线。

```rust
app.add_systems(
    Update,
    (collect_hits, mitigate_damage, apply_health, mark_dead).chain(),
);
```

- 每个系统只转换一种中间事实。
- `.chain()` 建立 happens-before 关系，代价是这条链失去并行机会。
- 没有数据依赖的系统不应习惯性串行；让调度器并行执行独立工作。

## 设计用法

按「收集 → 计算 → 写入 → 派生后果」拆分规则。中间结果可以是 Message、临时组件或资源，选择依据是它是否属于实体、是否需要跨帧保存、是否有多个消费者。

## 练习

将伤害结算拆成两段：护甲计算与生命值写入。先不加 `.chain()` 观察不确定性，再加入最小必要顺序。
