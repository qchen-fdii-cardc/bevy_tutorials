# Rust in Bevy：阶段 00 集成——运行时不变量

阶段实验不重讲文章 00 至 02；它检验你能否把可变 `App` 配置、Plugin 接口和 `Debug` 证据放进同一个运行时。

## 本阶段唯一主题

为运行时定义可观察的不变量：覆盖层开关不改变游戏状态，实体计数与 Query 计数一致，采样指标有明确时间窗口。

- 用 `debug_assert!` 保护仅开发期必须成立的关系。
- 日志字段记录输入、时间和计数，避免只有一句「失败了」。
- 测试 `RuntimeStats` 这类纯数据类型；窗口和 Gizmos 通过手工验收观察。

验收时先破坏一个不变量，再确认日志、断言或测试能指出错误位置。能看见错误，才谈得上修复它。
