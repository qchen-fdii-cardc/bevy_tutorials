# Rust in Bevy 19：幂等反馈与去重键

「播放音效」若在每帧条件成立时执行，就会变成每秒数十次播放。反馈系统要消费一次性事实，而非反复观察一个持久状态。

## 本章唯一主题

为反馈建立幂等边界：用事件 id、帧标记或已处理集合确保同一事实最多产生一次效果。

```rust
#[derive(Resource, Default)]
struct PlayedThisFrame(std::collections::HashSet<Entity>);
```

- 幂等意味着重复调用的可见结果不变。
- `HashSet` 的 key 必须标识一次事实；只用目标实体作 key 会错误合并该实体的两次受击。
- 去重集合要有清理时机，否则它会把历史永久当成「已播放」。

## 设计用法

由伤害 Message 或状态转换触发音效、闪白和 UI 提示；持久的 `Health <= 0` 更适合描述死亡状态，不适合每帧重播死亡音效。

将音频播放策略放在表现层。规则系统只产出可观察事实，因而可在无音频设备的测试中运行。

## 练习

让一次命中同时驱动声音与 UI 闪烁，并证明连续两帧观察到同一命中不会重复播放。
