# 最终 2D 游戏制作

路线图的最终交付是仓库根目录的 Cargo 项目，不属于任何单独教学章节。它只接收已经通过章节测试与阶段实验验收的机制，最终完成菜单、核心循环、暂停、存档、音频设置、失败重开与发布说明。

当前项目是可运行的最小 2D Bevy 宿主。随着路线推进，功能按独立插件和已验证的 ECS 规则进入这个目录。
